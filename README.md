# Projet : Automatisation d'une Infrastructure Réseau Multi-Services avec Ansible

## Objectif du projet

Ce projet a pour but d’automatiser la configuration d’un parc d’équipements réseau (Cisco IOS, Arista EOS, VyOS, etc.) à l’aide d’Ansible.
L’objectif est de :

garantir la cohérence des configurations réduire les erreurs humaines gagner du temps dans la gestion opérationnelle fournir un socle d’automatisation réutilisable et évolutif

## Environnement recommandé

Contrôleur Ansible : Linux (Ubuntu / Debian) Équipements cibles :
Routeurs et commutateurs Cisco IOS (réels ou simulés)

- via GNS3, Cisco CML, Containerlab, Cisco Sandbox ou équivalent

- Ansible ≥ 2.10


## Fonctionnalités mises en œuvre

1. Inventaire et test de connectivité
2. Collecte d’informations (Facts)
3. Sauvegarde automatique des configurations
4. Déploiement d’une configuration NTP uniforme
5. Gestion des utilisateurs et de la sécurité
6. Déploiement de VLANs via variables
7. Configuration d’interfaces IP
8. Utilisation de templates Jinja2
9. Audit de conformité (SNMP)
10. Rapport final (Markdown ou HTML)
11. cript Python Netmiko pour collecte d'informations supplémentaires
